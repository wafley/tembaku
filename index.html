⚡ TIPS & MEKANIKA KHUSUS

  • Isi Ulang Manual: Peluru tidak otomatis terisi saat habis. Tekan [R] atau tombol Reload!
  • Mata Sensor Boss: Saat Titan mengaktifkan Kinetic Shield, tembak tepat di mata sensor merah untuk 1.5x Critical Hit!
  • Flawless Wave: Bersihkan seluruh gelombang tanpa terkena serangan musuh untuk mendapatkan bonus skor 500x Wave!
  • Radar Tepi: Panah merah berdenyut di tepi layar menunjukkan posisi musuh di belakang atau samping Anda.

Jika kursor mouse tidak menggerakkan kamera, klik kiri di arena 3D untuk mengaktifkan kembali Pointer Lock API. Tekan [Escape] untuk jeda dan menampilkan kursor kembali.

📱 PERFORMA & TAMPILAN MOBILE

Game ini dirancang khusus untuk dimainkan dalam Mode Lanskap (Mendatar). Jika muncul peringatan rotasi, putar ponsel Anda ke posisi mendatar. Gunakan peramban Chrome, Safari, atau Firefox versi terbaru.
